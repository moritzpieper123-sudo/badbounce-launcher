# Libraries

Up: [[Home]]

Everything a Konzept engine can use, with a preview and a name. Open them in the launcher page **Libraries**.

| Folder | Konzept | What is inside |
|---|---|---|
| `Machines/` | K1 | every press in the machine registry |
| `Heads/` | K3 | merge-ladder heads, lowest tier first |
| `Flags/` | K5b | flag balls |
| `Weapons/` | K5b | every weapon the engine can draw, tag STANDARD MIX |
| `Bosses/` | K6b | the 100 bosses (BOSS=number) |
| `Shapes/` | K9 | the 100 shapes (K9_SHAPE=number) |
| `Boxes & effects/` | K10 | every box the arena can hold, tag STANDARD LAYOUT |
| `Sounds/<ID>/` | all 14 IDs | only the sounds each Konzept really plays |

Keep current: rebuild after every engine change, see [[Engine/Libraries/README|Libraries engine README]].
