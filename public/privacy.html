Privacy Policy

Badbounce Launcher is a private, personal tool used only by its owner (Moritz Pieper) to manage the TikTok channel @badb0unce. It is not offered to the public.

Gmail data

The app requests read-only access to Gmail (scope gmail.readonly) to show the owner's own inbox inside the launcher. It reads only sender, subject, date, snippet and unread status. It never sends, changes or deletes email.

Storage

The access token is stored encrypted on the owner's own PC. A short list of the latest inbox items is synced to the owner's private database (Supabase) so the owner can see it on their phone. No data is sold, shared with third parties, or used for advertising or AI training.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removal

Click Disconnect Gmail in the app, or remove access at myaccount.google.com/permissions. This deletes the stored token.
